# CS 5XX Candidates: Winter and Spring 2027

Scope: OSU CS 500-level graduate courses relevant to S-NodeFinder's research
direction (networking, distributed systems, security, and the anonymity
measurement work described in `ONE-PAGER.md` and `NEXT-TWO-SEMESTERS.md`).
Plan per `NEXT-TWO-SEMESTERS.md`: one course in winter, two in Spring 2027.

Source for every course below: the official OSU course catalog, Computer
Science (CS) section.
<https://catalog.oregonstate.edu/courses/cs/>
(PDF mirror of the same catalog entries: <https://catalog.oregonstate.edu/courses/cs/cs.pdf>)

All course numbers, titles, and descriptions were pulled directly from that
catalog page/PDF on 2026-08-22 and not inferred or guessed.

## Winter candidate (pick one)

### CS 577, Privacy and Surveillance, 4 Credits
Explores the need for privacy and theories of surveillance. Examines the
current state of privacy-enhancing technologies. Emphasizes the critical
reading and discussion of technical literature on privacy-enhancing
technologies.

Fit: this is the closest catalog match to the Diaz-style degree-of-anonymity
work at the center of the research question. Reading privacy-enhancing-tech
literature in a structured course would feed directly into computing *d* and
its stake-weighted variant.

### CS 578, Cyber-Security, 4 Credits
A broad overview of the field of computer and network security. Essential
cryptographic mechanisms such as symmetric and public-key cryptography
(e.g., encryption, signatures), network security and authentication
protocols (e.g., Kerberos, TLS, IPSec), system security (e.g., access
control, firewalls), advanced topics (e.g., searchable encryption, cloud
security, secure computation). Crosslisted as CS 578/ECE 578.

Fit: broader security foundation than CS 577, useful groundwork if the
sustained-spy / churn-dataset work (raised as the "one ask" to Dr. Ma) grows
into a security-adjacent contribution rather than a purely privacy-metric one.

Recommendation: CS 577 is the tighter fit to the stated research question.
CS 578 is the stronger fallback if it is not offered winter term or if a
broader security base is preferred first.

## Spring 2027 candidates (pick two)

### CS 576, Advanced Computer Networking, 4 Credits
Covers advanced computer networking concepts: queuing theory,
quality-of-service, buffer management, resource allocation and sharing,
service models, scheduling policies, and performance modeling and analysis.
Crosslisted as CS 576/ECE 576.

Fit: directly relevant to modeling gossip (CRDS) propagation, saturation
curves, and the RPC-view-versus-wire-view gap described in `ONE-PAGER.md`.

### CS 578, Cyber-Security, 4 Credits (see full entry above)
Take in spring if not taken winter.

### CS 577, Privacy and Surveillance, 4 Credits (see full entry above)
Take in spring if not taken winter.

Recommended spring pairing: CS 576 (Advanced Computer Networking) plus
whichever of CS 577 / CS 578 was not taken in winter.

## Distributed systems: no confirmed candidate

The CS 500-599 catalog listing does not contain a dedicated course titled
"Distributed Systems" (or an equivalent, e.g. distributed algorithms,
consensus, replication) as of this check. The closest adjacent courses are
CS 576 (Advanced Computer Networking) and CS 574 (Operating Systems II,
which covers networking as one topic among concurrency, memory management,
and file systems). Per the standing rule against inventing course numbers,
no distributed-systems course is listed here. If OSU has one under a
different subject code (e.g. ECE) or as a rotating CS 519/CS 599 special
topic, that would need separate confirmation against the catalog or the
class schedule before being added to this list.
